# AeroVisuals Free 1.1.0 — Minecraft 1.21.11

Отдельный проект бесплатной версии с Fabric ID `aerovisuals`: в одну папку mods устанавливается только одна редакция.

| Раздел | Что доступно |
|---|---|
| Inventory | InventoryHud, ShulkerPreview |
| HUD | ArmorHUD, Potions, Keystrokes, Totems, Saturation, Keybinds |
| PvP | Crosshair, HitSounds |
| Misc | Jump Circles, Item Physics, Footprints, World Particles, Death Coordinates, Armor Notifier, Experience Effects |
| Косметика | Cosmetics, Pet |
| Дополнительно | Постоянная ватермарка Island |

Всего зарегистрировано 20 модулей, включая ватермарку. Друзья и конфиги остаются самостоятельными разделами ClickGUI. Медиаплеер и остальные платные реализации физически удалены из исходников и JAR. Их обработчики, служебные классы и отдельные ресурсы также удалены. Импорт платного конфига не добавляет отсутствующие модули.

## Косметика

Для своего персонажа доступны семь предметов:

- Плащ — Броя V2, ID 100.
- Плащ — Броя V3, ID 101.
- Крылья — Purple monster, ID 123.
- Катана — ila_studio, ID 137.
- Новогодняя шапка, ID 19.
- Питомец — 1 Год, ID 126.
- Граффити — Петух, ID 127.

Ограничение применяется к выбору и локальной экипировке, включая загрузку настроек и экипировки с сайта. Полный каталог моделей и текстур сохранён; косметика других игроков рисуется по серверным ID без этого ограничения. Имена PNG из архива дополнены каноническими `texture.png`, которые ожидает рендер.

Существующая синхронизация экипировки через сайт сохранена. При смене Premium на Free для того же UUID его серверная экипировка приводится к доступному набору Free. Выбор Free проверяется в клиенте; отдельная серверная политика бесплатного каталога в этой задаче не добавляется.

## Вход и сохранение

Локальные функции Free доступны без подписки и без ожидания сети. Для друзей, облачных конфигов и отправки своей экипировки нужен вход в Aero ID через Aero Launcher. Free читает существующий файл авторизации, сравнивает указанный там HWID с компьютером и проверяет действительность сессии через `api/auth/me`; платная проверка подписки не вызывается. Публичный список косметики других игроков загружается и без входа. Недоступность аккаунта не блокирует локальные бесплатные функции.

Локальные настройки, профили и файлы облачных конфигов лежат отдельно в `config/aerovisuals-free/`. Списки друзей и серверные конфиги относятся к тому же Aero ID, что и в Premium.

## Сборка

Из этой папки: `gradlew.bat assemble -x test --offline --console=plain`.

Итог с предоставленным OBF: `build/release/aerovisuals-free-1.21.11-1.1.0-obf.jar`. Обычное имя в `build/libs/` содержит те же защищённые байты. Сырые JAR и таблицы переименований не предназначены для распространения.

Сборка выполняется локально, без тестов и запуска Minecraft. Публикация, изменение сервера и установка в лаунчер в эту задачу не входят.

## Состав JAR

Сборка содержит проверку упаковки `validateFreePackage` перед OBF. Разрешён точный список реализаций Free; платные пакеты, лишние вложенные модули и их графические ресурсы останавливают сборку. Фактический состав фиксируется в `build/free-content-manifest.json`. Тесты и игра для этой проверки не запускаются. Исходная резервная копия находится вне проекта Free.
