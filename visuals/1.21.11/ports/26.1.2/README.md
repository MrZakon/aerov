# AeroVisuals 1.0 — Minecraft 26.1.2

Отдельный перенос текущего проекта 1.21.11. Требуются Java 25, Fabric Loader 0.20.1
или новее и Fabric API для Minecraft 26.1.2. Исходники используют имена Mojang.

Сборка без тестов и запуска Minecraft:

```powershell
$env:JAVA_HOME='E:\Games\Prism Launcher\java\jdk-25'
.\gradlew.bat assemble -x test -x compileTestJava
```

Итоговый файл: `build/libs/aerovisuals-26.1.2-1.0.jar`.

Перенесены GUI, HUD, косметика, визуальные модули и интеграция сайта.
Оформление и расположение кнопок главного меню сохранены; изменены только
вызовы API для новой версии. Профили оформления используют отдельный путь версии 26.1.2.

Адаптированы извлечение GUI-состояния, события рендера мира, состояние камеры,
проекция TargetESP, Zoom, отрисовка игроков и предметов, чат, таб, инвентарь,
графические конвейеры и создание иконок через ItemStackTemplate.
В 26.1.2 используется новый штатный FramerateLimiter Minecraft: старый хук
RenderSystem.limitDisplayFPS из 1.21.11 сюда не переносится. Поведение окна
и настройки полноэкранного режима не меняются.

Косметика: ClickGUI → Косметика → «Сайт: подключить». Сессия Aero Launcher
подхватывается автоматически. Выбор на сайте и в игре синхронизируется;
мод отображает комплекты других подключённых игроков того же Minecraft-сервера.
Подробности подключения и API — в `MOD_COSMETICS_SYNC.md`.

Миграция выполнена по документации Fabric:
https://docs.fabricmc.net/26.1.2/develop/porting/

Сборка и статическая сверка точек mixin с байткодом выполнены.
Игровые и автоматические тесты не запускались. Удалённый сайт не развёртывался.
