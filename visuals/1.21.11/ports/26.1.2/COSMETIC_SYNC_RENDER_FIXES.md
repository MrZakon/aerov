# Исправления косметики — 1.21.11 и 26.1.2

Проверка выполнена чтением кода клиента, серверного API и исходных моделей.
Автоматические тесты, запуск Minecraft и запросы с изменением экипировки на рабочем сайте не выполнялись.

## Синхронизация

- Личный комплект и присутствие других игроков опрашиваются отдельными задачами.
  Сбой авторизации, сохранения или heartbeat больше не останавливает обновление чужой косметики.
- При конфликте ревизии используется объединение изменений по категориям.
  Снятие предмета — полноценное изменение. Если на сайте изменена другая категория,
  оба изменения сохраняются. При конфликте в одной категории приоритет у локального действия.
- Ответ, пришедший после нового выбора в GUI, объединяется с актуальным комплектом
  непосредственно в клиентском потоке. Старая сессия не может применить отложенный ответ после смены аккаунта.
- При переходе между мирами очищаются чужие комплекты; запоздавший ответ из старого мира игнорируется.
  Пустые комплекты из presence снимают старые предметы. При недоступном API действует прежний TTL 45 секунд.
- Изменение комплекта с сайта вызывает немедленный следующий heartbeat.
- GUI обновляет состояние кнопок при изменении экипировки с сайта.
  Убрана повторная установка поискового текста, которая могла бесконечно пересоздавать виджеты.

Протокол совместим с уже опубликованными маршрутами `/api/client/cosmetics/equipped`
и `/api/presence/...`; изменения серверной части для этих исправлений не требуются.

## Отображение

- Крылья, рюкзаки и головные украшения используют собственные `x/y/z`, `scale`,
  `yaw/pitch/roll` из комплектных файлов. Убраны общий масштаб по высоте модели,
  смещение по её центру и покачивание всей модели крыльев вокруг неверной точки.
- Крылья и рюкзаки закреплены на теле, украшения — на голове.
  Координаты и преобразования сверены с исходным рендерером SyndicateVisuals и LinkenVisuals.
- Исправлены преобразование осей, повороты вокруг куба и родительских костей,
  `inflate`, наследование `mirror`, UV верхней/нижней стороны и `uv_rotation`.
  Используется двусторонний материал для тонких деталей.
- Границы моделей рассчитываются по преобразованным вершинам.
  Питомцы ставятся нижней точкой на поверхность и правильно ориентируются в мире.
- Свои и чужие питомцы используют общее следование по поверхности в мировом рендере.
  Они исчезают после снятия и больше не приклеиваются к телу другого игрока.
- Исправлены направление, длина и последний участок текстуры плаща; граффити обращено вверх.

Описание формата геометрии: https://mojang.github.io/bedrock-samples/Schemas.html

Оформление главного меню не изменено. Исправления собираются в обеих версиях
командой `assemble -x test -x compileTestJava`.

Фактический вид и полный обмен между двумя запущенными клиентами этой проверкой не подтверждены:
по запросу пользователя выполнены разбор кода и сборка без игровых проверок.
