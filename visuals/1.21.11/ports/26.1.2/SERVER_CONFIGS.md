# Конфиги Aero Cloud

ClickGUI → **Конфиги**, в Minecraft 1.21.11 и 26.1.2.

- «Создать» сразу сохраняет текущие настройки на ПК, затем отправляет их в Aero ID в фоне. Сеть не блокирует локальное сохранение.
- Выбор карточки открывает применение, переименование, перезапись и удаление. Перезапись и удаление требуют подтверждения.
- «Поделиться» открывает доступ по коду и копирует код в буфер. Импорт создаёт отдельную личную копию, которую владелец оригинала не может изменить.
- «Закрыть доступ по коду» прекращает новые импорты; уже импортированные копии остаются у получателей. При следующем открытии доступа создаётся новый код.
- Сохраняются состояния и настройки модулей, бинды, расположение HUD, оформление и состояние ClickGUI. Друзья, точки на серверах, косметическая экипировка, HWID и авторизация в конфиг не входят.
- «Применить» использует локальную копию, если она соответствует известной серверной ревизии. Если копии нет или серверная версия обновилась, клиент скачивает JSON, атомарно сохраняет его на ПК и применяет. Импорт по коду тоже скачивает локальную копию.
- Файлы лежат в папке экземпляра игры: `config/aerovisuals-configs/<хеш сайта>/<Aero ID>/<UUID>.json`. JSON содержит настройки в `data`, метаданные и очередь изменений. Данные разных Aero ID разделены. Файл `accounts.json` содержит только хеши сессий и ID аккаунтов; токенов авторизации в нём нет.
- Создание, перезапись, переименование и изменение доступа сначала сохраняются локально. Очередь переживает перезапуск и повторяет временно неудавшуюся отправку с задержкой 2–30 секунд. У каждой записи и операции есть UUID, поэтому повтор запроса не создаёт дубликат.
- После подтверждения удаления настройки сразу удаляются из локального файла и карточка исчезает. До ответа сервера остаётся только журнал удаления; после подтверждения сервера удаляется и он. Сервер сохраняет отметку UUID, которая блокирует запоздавшую загрузку удалённого конфига. Повторное удаление безопасно.
- Кнопка удаления закреплена внизу правой панели; подтверждение выводится по центру поверх интерфейса. Для подтверждения не требуется прокручивать панель.
- Применённые настройки переживают перезапуск. Обычные правки модулей не перезаписывают пресет автоматически: используется явная команда сохранения. При конфликте с правками другого клиента очередь останавливается, сохраняя локальную копию; повторное подтверждённое сохранение использует актуальную серверную ревизию.
- Формат `aerovisuals-config`, версия 1, общий для обеих версий игры. Старые конфиги другого формата отображаются, но не применяются автоматически.

Сервер использует коллекцию `visuals/user_configs` общей MySQL-базы и привязку Aero ID → профиль Visuals. `config_sequence` предотвращает повторное использование ID, `config_deletions` хранит отметки удаления. До 100 конфигов на аккаунт, размер одного до 2 МБ. Повторяющиеся названия запрещены; импорт одноимённого конфига получает числовой суффикс. Revision защищает перезапись от конфликта с другим клиентом.

API (авторизация существующей сессией Aero Launcher):

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/client/configs` | Личные карточки без содержимого |
| POST | `/api/client/configs` | Создать: `name`, `data`, `clientId`, `operationId` |
| GET | `/api/client/configs/:id` | Загрузить собственный конфиг |
| POST | `/api/client/configs/:id` | `revision`, `operationId` + `name`, `data` или `private` |
| DELETE | `/api/client/configs/:id` | Удалить собственный конфиг; повтор даёт успех |
| POST | `/api/client/configs/delete` | Удалить по `clientId`, в том числе при потере ответа на создание |
| POST | `/api/client/configs/import` | Скопировать общий конфиг: `code` |

Сеть выполняется асинхронно; диск обслуживает отдельная последовательная очередь. Снимок состояния и применение выполняются в потоке Minecraft. Перед отправкой очереди сервер подтверждает Aero ID текущей сессии. При смене авторизации устаревший результат не применяется. Постоянные ошибки и конфликты не повторяются автоматически; временные ошибки повторяются с тем же ID операции.

Источник сравнения Pulse: `pulse/gui/config/ConfigActionMenu.java`, `ConfigListPanel.java`, `pulse/config/LocalConfigManager.java`. Найденный `CloudConfigRepository.java` содержит пустые методы, поэтому серверная реализация Aero написана отдельно.

Сборка: `assemble -x test`, существующая задача `protectRelease` с Fabric Obfuscator. Тесты и игра не запускаются.
