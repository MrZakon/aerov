# AeroCore 26.3

В исходники Launcher-C добавлен отдельный тип сборки **AeroCore**.
Это готовый нативный движок Horizon v0.2.91 для Minecraft 26.3, а не Fabric-мод.
Внутренние экраны и исполняемые файлы upstream сохраняют название Horizon.

После следующей сборки лаунчера: «Менеджер версий» → «AeroCore» → «Установить».
Установка автоматически скачивает официальный архив движка, оригинальные файлы
Minecraft 26.3, библиотеки, звуки и Java 25 для подготовки ресурсов. Все загрузки
проверяются по контрольным суммам. Rust, Python и компиляция игры не нужны.
Первый запуск требует интернета и свободного места для нескольких ГБ данных.

Движок устанавливается в `<каталог игры>/engines/AeroCore/v0.2.91`.
Миры и настройки находятся отдельно в `<каталог игры>/instances/AeroCore 26.3`.
Для установки и восстановления используется PowerShell Windows. Журнал установки:
`engines/AeroCore/v0.2.91/install.log`. Кнопка «Починить» повторно проверяет загрузки
и готовит ресурсы. Неудачная установка не помечается готовой.

Запуск использует выбранный игровой профиль. Microsoft-сессия передаётся через
временный файл, который движок удаляет после чтения. Fabric JAR-моды с этим движком
несовместимы. Существующие Java/Fabric-сборки запускаются прежним способом.

Изменения внесены только в исходники. Компиляция и запуск установки/игры не выполнялись;
полная проверка работы требует последующей сборки Launcher-C и пробной установки.
Существующие EXE лаунчера этих изменений пока не содержат.

`src/game/AeroCoreInstall.ps1` — читаемая копия установщика.
Его содержимое встроено в `src/game/AeroCoreScript.h`; при изменениях эти файлы
нужно синхронизировать. Установщик извлекается на диск при установке AeroCore.
Название AeroCore относится к профилю интеграции; лицензии и авторство Horizon сохранены.
